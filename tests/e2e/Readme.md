# End-to-End Testing - 端對端測試

## 📋 概述

本目錄包含針對 Local LLM API 的端對端（E2E）測試案例，模擬實際用戶操作流程，驗證系統整體功能、流程與多模組協作的正確性。

## 🎯 測試設計目的

### 核心目標
1. **驗證完整流程**：測試從輸入到回應的全流程，確保各模組協作無誤
2. **多輪對話與知識查詢**：驗證多輪對話、FAQ 查詢、程式碼解釋等複雜場景
3. **多語言與情境切換**：測試多語言切換與多情境應用

### 測試策略
- **多輪對話**：模擬用戶與 LLM 多輪互動
- **知識查詢**：測試 FAQ、知識庫查詢
- **程式碼解釋**：驗證 LLM 對程式碼的理解與說明能力
- **多語言切換**：測試對話過程中語言切換的正確性

## 📝 測試案例說明

### TC-E2E-0001: 程式碼與解釋
**檔案**: `test_code_and_explanation.py`
- 測試 LLM 對程式碼片段的解釋能力

### TC-E2E-0002: FAQ 知識查詢
**檔案**: `test_faq_knowledge_query.py`
- 測試 FAQ 查詢流程

### TC-E2E-0003: 多輪對話
**檔案**: `test_multi_turn_conversation.py`
- 測試多輪對話流程

### TC-E2E-0004: 多語言切換
**檔案**: `test_multilingual_switch.py`
- 測試對話過程中語言切換的正確性

## 🔧 執行方式

```bash
pytest tests/e2e/ -v --alluredir=allure-results
```
